# Plan Studio

Browser floor plan and 3D home design tool: 2D editor, 3D view, first person walk, furniture, finishes, extensions, rainwater tanks, Glide Inside branded drawing set (PDF, DXF), 3D export (GLB, OBJ), and a paid Plan Pack with a Claude Haiku design assistant and credit metering.

Plain ES modules, no framework. three.js 0.186.1, jsPDF 4.2.1, pdf.js 4.10.38.

## Set up

```
npm install
```

The app loads three.js, pdf.js and jsPDF from `./vendor`, which must point at the installed packages:

- macOS or Linux: `mkdir -p vendor && ln -s ../node_modules/three vendor/three && ln -s ../node_modules/pdfjs-dist vendor/pdfjs && ln -s ../node_modules/jspdf vendor/jspdf`
- Windows (PowerShell): `mkdir vendor; Copy-Item -Recurse node_modules\three vendor\three; Copy-Item -Recurse node_modules\pdfjs-dist vendor\pdfjs; Copy-Item -Recurse node_modules\jspdf vendor\jspdf`

## Run

```
python -m http.server 8100
```

Open http://localhost:8100/ (add `?dev=1` to unlock the paid exports locally).

## Test and build

- `node --test tests/*.test.mjs` runs the unit tests.
- `python3 tools/smoke.py index.html --out shot.png` runs a headless browser check (needs Python Playwright).
- `node tools/build-single.mjs` writes `dist/plan-studio.html`, the whole tool in one file.

## Layout

| Folder | Contents |
|---|---|
| `src/model/` | Project schema, geometry, the operations registry (every edit goes through it), store with undo |
| `src/editor2d/` | 2D plan editor (canvas) and its tools |
| `src/viewer3d/` | 3D model build, viewer, finish picker, edit mode, walk mode, doors, stairs |
| `src/catalogue/` | Furniture, finishes and colours, opening presets, tanks, templates |
| `src/ui/` | App shell, panels, wheel and inventory, title block form, onboarding tour and tips |
| `src/premium/` | Plan Pack: upgrade flow, AI assistant client, credits, exporters (PDF, DXF, GLB, OBJ), PDF import, branding |
| `server/` | Web standard back end (checkout, Stripe webhook, entitlements, AI proxy with credits, exports); see `server/README.md` |
| `docs/SCOPE.md` | Full product and integration brief |
| `src/config.js` | Brand, price, links and feature flags |

The Next.js website copy of the back end lives in the website repo under `frontend/src/lib/plan-studio-server/` and is generated by `server/sync-to-site.mjs`.
