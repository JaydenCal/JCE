Vendored libraries (no CDN, the app stays self contained).

- proj4.cjs: proj4js 2.15.0, MIT licence (https://github.com/proj4js/proj4js). Coordinate system transforms for boundary upload.
- fflate.js: fflate 0.8.x browser ES build, MIT licence (https://github.com/101arrowz/fflate). Reads KMZ and zipped shapefiles.
